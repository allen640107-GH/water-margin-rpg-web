# 水滸傳：替天行道（網頁 RPG）

以《水滸傳》前半部為藍本的回合制角色扮演遊戲。純前端、免安裝、免帳號，手機（含折疊機外螢幕／展開、iPhone SE）與電腦皆可遊玩。

**立即遊玩：** https://allen640107-gh.github.io/water-margin-rpg-web/

## 2.0.0 美術全面升級
- **片頭動畫**：風雪山神廟、景陽岡打虎、梁山聚義三段影片（約 14 秒，2.0 MB），首次開啟自動播放（靜音，點畫面開聲音），右上大「跳過」；標題選單可「觀看片頭」重播。
- **動態標題**：循環影片（水波、旗幟、霧氣）＋ CSS 飄霧、迎風大旗、行走的好漢剪影；影片無法播放時顯示靜圖。
- **全身行走角色**：15 位好漢、8 種 NPC、13 種雜兵／野獸、10 名頭目，全部改為全身立繪，4 方向 × 3 格行走動畫（`img/spr/`）。
- **地圖重繪**：手繪無縫地表（草地、土路、石板、木地板、雪地、沙地、水面、岩地）柔邊混合；建築改為瓦房／茅屋／雪屋／山寨／大殿／酒樓／衙門等立面圖並附門；樹木、竹林、蘆葦、岩壁、城牆、寶箱、推石等皆為立體物件並依 y 排序；水面動態波紋。
- **戰鬥**：我方好漢以全身戰鬥立繪登場（直式畫面在下方、橫式／電腦在右側），行動、受擊、倒下皆有動作；好漢當頭目時亦用全身立繪。
- **存檔**：存檔版本 1 → 2 自動遷移，遷移前備份原始資料為 `.bak.v1`；1.0.0 的存檔可直接在 2.0.0 繼續（`tests/fixtures/` 為 1.0.0 實際產生的存檔）。
- 地圖格線、劇情、謎題、戰鬥數值均未刪減，遊玩時間估算不變。

## 系統
- 回合制戰鬥：攻擊／技能／道具／防禦／逃跑／自動；敵方依人數調整強度；頭目有固定出招與狂暴。
- 等級與經驗（後備成員獲得一半經驗）、武器／防具／飾品裝備、專屬技能、道具、商店、客店休息。
- 謎題：推石機關、壓板與機關門、水路迷宮、盤陀路（白楊樹）迷宮。
- 支線：鄆哥的雪梨、獵戶的請託、金色鯉魚、西溪村強人、梁山操練、蓼兒洼水寨、黑風洞、鍾離老人的井、扈太公的心事、演武場五連戰等。
- 存檔：自動存檔＋三個手動欄位（localStorage）。存檔含版本欄位與遷移；遷移前備份原始資料；較新版本存檔不覆寫；損壞資料先備份。

## 遊玩時間估算（首次遊玩、不刷怪）
以 `node tools/playtime.mjs` 計算：

| 內容 | 估計 |
|---|---|
| 第一回 | 約 50 分 |
| 第二回 | 約 50 分 |
| 第三回 | 約 46 分 |
| 第四回 | 約 49 分 |
| 第五回 | 約 53 分 |
| 第六回 | 約 57 分 |
| 主線小計（含主線地圖內支線） | 約 5 小時 05 分 |
| 純支線地圖（蓼兒洼、黑風洞、演武場） | 約 41 分 |
| **合計** | **約 5 小時 46 分** |

估算方法：對話每句 1.2 秒＋字數÷7 字/秒；每場戰鬥 15 秒＋回合數×(我方人數×3 秒選指令＋行動數×0.9 秒動畫)，回合數取自平衡模擬 `tools/sim.mjs`；移動以 BFS 最短路徑貪婪走訪所有互動點×0.2 秒×1.4；每個謎題 4 分鐘；每張有商店/客店的地圖 2 分鐘整備。未計入戰敗重來、反覆查看選單與重複對話，實際時間通常更長。

交叉驗證：`node tools/playtime_alt.mjs` 用另一套較寬鬆的假設（對話每句 2.5 秒＋每字 0.12 秒、探索以可走格數×0.6 秒計）估得一般玩家約 7.2 小時；若跳讀對話並大量使用自動戰鬥，下限約 3.7 小時。

## 操作
- 手機：點地圖自動走過去，或用左下方向盤；右下「調查」與人物交談、開寶箱。對話點一下繼續。
- 電腦：方向鍵／WASD 移動，空白鍵／Enter 調查，Esc／M 開選單；滑鼠點地圖亦可移動。
- 右上 ♪ 可開關音樂。

## 開發
無建置步驟，原生 ES Modules。本機執行：`python3 -m http.server 8765` 後開啟 http://localhost:8765/

- `node tools/validate.mjs`：資料驗證（地圖字元、出入口、可達性、劇本指令、條件、物品、旗標引用）＋內容統計
- `node tools/sim.mjs`：依章節順序的戰鬥平衡模擬
- `node tools/playtime.mjs`：遊玩時間估算
- `python3 tests/play.py [網址]`：六種螢幕尺寸自動遊玩（Playwright；片頭跳過→標題→第一回戰鬥→存讀檔）
- `python3 tests/save_migration.py [網址] [1.0.0 網址]`：存檔遷移測試（v0→v2、1.0.0 實際 v1 存檔→v2、不降級、損壞資料備份）
- `python3 tools/process_art.py`／`python3 tools/process_sprites.py`：`art/src/` 原圖 → `img/` WebP（行走圖切格、去背、腳底對齊）
